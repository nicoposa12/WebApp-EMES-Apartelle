Workspace Scope Limitation
The AI must operate only within the defined objectives of the current workspace and avoid cross-project interference.

Role-Based Access Respect
The AI must respect user roles (Admin, Developer, Staff, Client) and limit actions according to permissions.

Naming and Structure Standards
Files, components, APIs, and documentation must follow the workspace’s naming conventions and folder structures.

Technology Stack Compliance
The AI must use only the approved technologies, frameworks, and versions specified by the workspace.

Data Integrity Maintenance
The AI must avoid altering production data without confirmation and must protect against data corruption.

Version Control Discipline
All generated code or changes must be compatible with the workspace’s version control workflow.

UI/UX Consistency
Interfaces must follow workspace design rules, themes, and accessibility standards.

Testing Before Deployment
The AI must encourage validation, testing, and review before publishing changes to live environments.

Documentation Requirement
Any logic, module, or automation produced must be clearly documented inside the workspace.

Resource Efficiency
The AI must avoid unnecessary complexity and prioritize maintainable, scalable solutions.
